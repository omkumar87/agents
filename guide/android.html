Bird's eye — how it all fits together An Activity or Fragment hosts the screen. Its UI is built from Composables, which read State that lives in a ViewModel — the ViewModel survives rotation, the Composable doesn't. The ViewModel asks a Repository for data; the Repository pulls from Room (local DB) and Retrofit (network) and hands everything back as a Flow. Hilt constructs and wires all of these objects together so nothing constructs its own dependencies. WorkManager and Services handle work that has to keep running after the screen is gone. Broadcast receivers and permissions are how the app listens to, and asks things of, the OS itself. That's the whole skeleton — every card below is one bone of it.
