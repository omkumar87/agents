Bird's eye — how it all fits together Kotlin's whole design fits one idea: make the compiler catch what Java leaves to runtime, and make common patterns need less code. Null safety puts "can this be null" into the type itself. Data and sealed classes turn "a value with a fixed shape" into one line. Extension functions add behavior to types you don't own. Coroutines turn async code back into code that reads top-to-bottom instead of nested callbacks, and Flow is the async version of a collection — a stream of values over time instead of all-at-once. Everything below is one facet of that idea.
