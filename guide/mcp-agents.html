Bird's eye — how it all fits together An LLM call alone is just text in, text out. An agent wraps that call in a loop — observe, decide, act, observe the result, repeat — and tool calling is how it actually DOES something instead of just describing what it would do. RAG is how it answers with information it wasn't trained on. MCP standardizes the tool-calling part: instead of every app writing custom glue to every tool, MCP gives one protocol any client can speak to any compliant server, so a Host app connects Clients to Servers that expose Tools, Resources, and Prompts over a shared wire format. Everything below is one piece of that chain.
